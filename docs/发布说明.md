# v1.0.0 离线候选包（草稿，待真实 QQ 验收）

当前不是正式开箱即用版本；尚未完成真实 QQ 收发、主动发言和真实 DeepSeek 图片/文字调用验收。`v1.0.0` 正式标签和发布须等用户集中实测通过，不创建中间 v0.x。

Windows 用户包：`QQ-AI-Bot-v1.0.0-Windows-x64.zip`；完整源码：`qq-ai-bot-starter-v1.0.0-source.zip`；校验文件：`SHA256SUMS.txt`。

系统要求：Windows 10/11 x64，建议至少 3 GB 空间。完整解压后双击 `启动机器人.bat`；首次安装需要联网下载固定依赖，不能离线首次启动，无需预装 Python、Git 或 Docker。包内已有官方 Python 3.12.10、AstrBot 4.29.0 源码/原生 WebUI、uv 0.9.5、四人格与轻量插件。

必填配置：用户自己的 DeepSeek Key、官方 QQ 机器人扫码授权、模型提供者 ID、AstrBot 管理员发送者 ID和插件允许群 ID。群消息访问范围、主动发言许可需要在 QQ 中设置；只能加入官方允许、用户有权限的群。API Key 和 QQ 凭据只能在本机面板填写。

功能：管理员显式开启的主动接话、四人格、静态图片/表情首帧理解、10 分钟短期上下文、默认关闭的手动长期记忆、趣味命令、真实作品本地推荐、预算/并发/冷却/退避、默认内容脱敏日志。普通文字不会逐条触发模型判断。

已知限制和验收证据见仓库 `docs/验收报告.md`；首次启动与原生登录实际通过，不能替代真实 QQ 或视觉效果验证。推荐作品库较小；无联网搜索、语音/视频、多帧 GIF 理解或自动长期画像。
