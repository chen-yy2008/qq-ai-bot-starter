# v1.0.0-rc.1 公开候选修复

此候选版修复自研插件对群内原生命令的拦截，增加不含正文和身份的安全诊断，并提供经过下载校验、备份和失败恢复的一键更新。**尚未完成真实 QQ A–E 验收，不是正式 v1.0.0。**

新用户下载 QQ-AI-Bot-v1.0.0-rc.1-Windows-x64.zip，完整解压后从最外层双击 **启动机器人.bat**。首次设置与重置密码使用相同的本地 Windows 窗口，两个密码框各有显示/隐藏按钮，默认隐藏。随后首次联网安装固定依赖；无需预装 Python、Git 或 Docker。框架仍为 AstrBot 4.29.0，Python 3.12.10，uv 0.9.5。

旧安装无需重装：下载 **QQ-AI-Bot-Update-Start.bat**，双击选择现有目录，查看版本和文件清单后确认。它只下载校验固定来源的项目更新器，再使用原安装的 Python 完成更新。以后直接双击安装目录顶层 **检查并更新.bat**。不需要自己找内部目录、解压或复制插件。

QQ-AI-Bot-Update.zip 与 QQ-AI-Bot-Update.json 为更新器使用的修复资产和清单，不应整体覆盖 data/plugins。qq-ai-bot-starter-v1.0.0-rc.1-source.zip 提供对应完整自有源码，框架源码和第三方声明另见整合包。资产校验值在 SHA256SUMS.txt。

默认只更新清单列出的自有插件和必要启动/更新程序及说明。不覆盖 Key、QQ 凭据、管理员、允许群、人格、记忆数据库或其他插件。不重新安装 AstrBot 或 Python，不添加驻留服务、开机任务或强制更新。

无回复时用顶层 **安全诊断.bat** 开启一次诊断，重启、复现、查看后关闭；最多一小时自动失效。保留正常隐私日志，固定阶段和错误类别能用于排查，原文和异常原始响应不会公开。

真实 API 费用由用户承担；群成员知情后再开启上下文、长期记忆或主动模式。真实 QQ 权限、模型能力和接梗时机仍需用户实际测试。详见 [更新与诊断](更新与诊断.md)、[真人验收](真人验收清单.md) 和 [验收报告](验收报告.md)。
