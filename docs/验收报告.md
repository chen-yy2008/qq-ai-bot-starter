# v1.0.0-rc.1 候选修复验收

日期：2026-10-15。状态：**真实 QQ A–E 尚待用户验收，不是正式 v1.0.0**。

## 定位依据

原 `plugin/main.py` 使用 priority=100 接收全部群事件；未在允许群时直接 stop_event，已允许群也在 finally 中无条件 stop_event。锁定框架 StarHandlerRegistry 按高优先级先执行，StarRequestSubStage 遇 stopped 就跳过后续处理器。因此能在真实九阶段调度器中复现“关闭插件 /help 正常、开启插件 /help 与 /sid 无回复”。

此外，4.29.0 的 AstrMessageEvent.should_call_llm 文档定义参数为“禁止默认请求”，ProcessStage 判断 not event.call_llm 才启动默认代理。旧代码传 False 不能防止第二条默认模型路径。修复仅对自研负责的 QQ 群消息传 True，原生命令保持框架行为。

旧 `/身份` 在离线真实适配器中能发出，不能把用户真实平台上的该项失败武断归结为同一行。现在身份初始化先于授权和模型，显式普通文本发送，并记录不含正文和身份的发送阶段。真实 QQ 仍需验证。
