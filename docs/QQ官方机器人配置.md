# QQ 官方机器人配置

仅支持 AstrBot `v4.29.0` 的 QQ 官方 WebSocket 适配器。参考 [AstrBot 官方步骤](https://docs.astrbot.app/en/platform/qqofficial/websockets.html)；平台能力会变化，遇到账号限制以 QQ 的实际页面为准。

在 AstrBot 原生 WebUI 打开“平台 → 添加适配器 → QQ 官方机器人（WebSocket）”，优先选择“一键扫码配置”。在手机 QQ 扫码并确认，框架会填写 AppID 和 AppSecret。保持启用并保存。不要将这些凭据放入公开配置文件。

打开手机 QQ 的“联系人 → 机器人”，进入机器人的资料卡，选择“添加到群聊”。官方文档目前说明仅能加入你作为群主的群；不能承诺加入任意群。

在群设置的机器人配置中，把消息访问范围设为“全部群消息”，并开启“允许机器人主动发言”。仅收到 @ 消息时，插件无法看见普通讨论，也就没有真实群上下文；本地程序不能绕过这项权限。

如果扫码配置不可用，可在 [QQ 开放平台](https://q.qq.com/) 申请机器人、设置测试沙箱和 IP 白名单，再使用手动方式填写 AppID/Secret。家庭网络出口 IP 变化可能导致连接失败。请先确认该账号确实获得官方所需权限。

框架管理员与 QQ 群管理角色是不同权限来源。本插件以 AstrBot 的 `event.is_admin()` 为准；先用 `/身份` 获取官方平台返回的发送者 ID，再在本机面板添加管理员。允许群列表、插件群内授权、上下文告知、长期记忆告知、主动档位分别生效，不会因为扫码成功而自动开启数据收集。

真实验收由用户在自己的环境完成：确认普通文本到达；确认 @/指令能回复；开启自然/活跃后在正常讨论中观察受冷却约束的插话；确认 `/闭嘴` 生效；发送一张普通静态图片；用两个人格对同一主题提问；添加、查询并删除一条自愿共享记忆。账号登录、群授权、模型 Key 必须由用户本地操作，自动测试不代替这一过程。
