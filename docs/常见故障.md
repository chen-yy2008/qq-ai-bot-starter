# 常见故障

| 现象或自检代码 | 原因与处理 |
| --- | --- |
| 首次安装失败 / DEPENDENCY MISSING | PyPI 网络、代理、磁盘空间或安全软件拦截。确认可访问 pypi.org / files.pythonhosted.org，重新双击启动；安装严格验证锁文件哈希，不会自动换不明镜像。 |
| PYTHON 或 RuntimeMissing | 未完整解压、被安全软件隔离或下载损坏。校验 ZIP SHA256，重新解压到有写入权限的目录。 |
| 6185 被占用 | 已有本包或其他 AstrBot 在运行。先正常停止旧窗口，不会强行杀死其他进程。 |
| 插件不显示 / PLUGIN MISSING | 检查 `data/plugins/astrbot_plugin_qq_ai_lab` 是否完整，只使用锁定的框架版本，禁止通过面板自动更新框架后继续宣称兼容。 |
| QQ_ADAPTER NOT_CONFIGURED | 在原生面板配置并启用 QQ 官方 WebSocket，按 QQ 页面完成本地扫码。 |
| QQ 配置存在但无消息 | 配置存在不代表连通。检查 QQ 绑定、IP 白名单、机器人是否入群、群消息访问范围和平台连接状态。自检不会把“有配置”当作实测通过。 |
| 普通消息不进入上下文 | 检查“全部群消息”、允许群列表、群内 `/启用群聊` 与 `/上下文`；个人退出也会排除本人的消息。 |
| 不主动说话 | 默认安静；需开启上下文、自然/活跃档、解除静音，并在 QQ 中允许主动发言。北京时间休息、候选概率、少于两人三条短对话、长篇讨论、费用预算和冷却都可能使机器人保持安静。 |
| Key 无效或无权限 | 在本机模型页面重新填写 Key，确认使用官方 HTTPS 地址并检查账户权限。不要分享原始响应或 Key 截图。 |
| 模型 ID / 图片能力不兼容 | 检查模型 ID，建议 `deepseek-flash`；关闭图片后用文字 `/自检`。图片失败不自动发第二个付费请求。 |
| 限流 / 余额不足 | 检查模型账户余额与请求限制，等退避期结束；插件不循环重试。 |
| 请求超时 / 网络连接失败 | 检查网络和供应商地址；请求会超时终止，失败保留预算。下一条新请求也必须符合退避限制。 |
| 今日预算到上限 | `/状态` 查看请求、Token 和估算费用；每日按北京时间更新，修改配置应由管理员在本机操作。 |
| 图片读取失败 | 仅允许公网 HTTPS，拒绝内网、本地文件和重定向；只处理首张、首帧，最多 4 MiB、1600 万像素，每群间隔至少 60 秒。部分 QQ 表情并不提供可下载图片。 |
| 操作需要管理员 | `/身份` 获取发送者 ID，在 AstrBot“访问控制”加入自己的 ID，保存并按框架提示生效。QQ 群管理员并不自动获得 AstrBot 管理员身份。 |

诊断入口为 `自检.bat` 和群内 `/状态`、`/自检`。默认框架日志只保留事件类型，隐藏消息、错误正文和堆栈。依赖安装的原始错误仅在内存中分类后丢弃，`data/install-status.txt` 只保存 `NETWORK_FAILED`、`HASH_MISMATCH`、`DISK_OR_PERMISSION_FAILED` 或 `DEPENDENCY_INSTALL_FAILED` 等代码；`start-status.txt` 保存启动失败代码。

图片、安全过滤和人格提示词都不能保证模型百分之百理解梗或永不输出不恰当内容。可用 `/图片 关闭`、`/别吐槽我`、`/闭嘴` 或 `/停用群聊` 及时控制体验。
