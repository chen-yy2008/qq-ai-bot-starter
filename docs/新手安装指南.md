# Windows 新手安装指南

当前是离线候选包，真实 QQ 和 DeepSeek 调用尚待本地授权验收。以下是实际启动和配置流程，不代表 QQ 实测已通过。

首次设置与重置共用的本地窗口（实际 Windows 控件截图，无真实密码）：

![本地密码设置窗口，两个密码框各有小眼睛](password-window.png)

1. 在仓库 Releases 下载 Windows x64 用户 ZIP，核对旁边的 `SHA256SUMS.txt`。不要下载 GitHub 自动生成的源码 ZIP 来代替用户包。
2. 右键“全部解压”到自己有写入权限的目录。ZIP 内不再套一层同名项目目录；解压后第一眼就能看见 `启动机器人.bat`、`打开管理面板.bat`、`停止机器人.bat`、`重置管理密码.bat` 和 `首次使用.html`。依赖和框架集中在“程序文件”，说明在“使用说明”；无需进入内部目录。建议至少 3 GB 可用空间，不要在压缩包中直接运行。
3. 双击 `启动机器人.bat`。**首次先弹出 Windows 本地密码设置窗口**，两个密码框各有小眼睛，默认隐藏，允许分别显示/隐藏。密码要求 12–128 位，含大写字母、小写字母和数字；两次输入必须一致。错误会显示在窗口中，取消不会覆盖已有配置。保存后明确显示登录地址和用户名，请保存好密码。随后首次联网安装固定依赖，可能持续数分钟；无需安装系统 Python。
4. 等待浏览器自动打开 `http://127.0.0.1:6185`，默认用户名 `astrbot`，使用刚设置的密码登录。已有安装的自定义用户名、端口会保留，准确地址和用户名会显示在设置成功窗口。浏览器未弹出时双击 `打开管理面板.bat`。重启保留密码，不会重复初始化；继承的密码或重置环境变量不能代替本地窗口。
5. 在原生面板“模型提供商”中新增 **OpenAI 兼容 / DeepSeek** 连接：地址 `https://api.deepseek.com`，Key 填你自己的 Key，模型 ID 填 `deepseek-flash`。记录创建后的模型“提供者 ID”。不要把 Key 发送到群或聊天中。模型可以更换，但必须支持所启用的文本/图片能力。
6. 根据 [QQ 配置指南](QQ官方机器人配置.md) 添加官方 WebSocket 适配器，扫码连接，把机器人添加到自己有权限的群中。群设置需要允许访问全部消息和主动发言，才能体验普通消息上下文与主动接梗。
7. 在群里发送 `/身份`，获取**自己的发送者 ID**和本群 ID。在 AstrBot“配置文件 → 访问控制”把自己的发送者 ID 加入管理员列表；不要把群 ID 当成管理员 ID。官方 QQ 的 ID 可能是 OpenID，不是显示的 QQ 号码。
8. 在插件“QQ 毒舌群友”的配置中，将群 ID 加入 `allowed_groups`，将第 5 步的模型提供者 ID 填入 `provider_id`。保存并重载插件；找不到插件时先运行 `自检.bat`。
9. 在群中发送 `/启用群聊 已告知群友`，然后 `/自检` 和 `/吐槽 今天的天气`。模型连接失败会返回分类错误，不会公开原始错误或 Key。
10. 先向成员说明“开启后最近最多 24 条、每条 400 字、最长 10 分钟的消息可能发给 DeepSeek”。再由管理员发送 `/上下文 开启 已告知群友`。需要主动发言时发送 `/主动 自然` 或 `/主动 活跃`。默认休息时段为北京时间 00:00–08:00。
11. 长期记忆独立默认关闭；先告知群友并得到同意，再发送 `/长期记忆 开启 已告知群友`，用 `/记住 自愿共享的内容` 手动添加。不要记录退出成员、凭据、身份证件或私人困境。退出记忆只能自动清理以本人身份添加的条目，管理员负责删除他人误录的信息。

默认每群明确触发冷却 20 秒；自然模式至少冷却 120 秒、活跃模式至少 60 秒。每群每日最多 60 个模型请求、60,000 Token、8 次主动候选；全局最多 200 个请求和 200,000 Token。图片每群至少间隔 60 秒、单张最多 4 MiB，仅处理第一张的首帧。休息、预算不足或模型认为不该说话时，主动模式保持安静是正常行为。

`/闭嘴` 即时阻止主动发言，明确命令和 @ 仍可用；`/开麦` 恢复先前档位；`/主动 安静` 彻底关掉主动档位。`/停用群聊` 撤销本群授权并清空短期上下文。`/清空记忆` 删除本群长期记忆。停止服务可双击顶层 `停止机器人.bat`；旧版启动窗口可按 Ctrl+C。查看日志请用本地 WebUI；隐私模式隐藏消息和异常内容，不建议关闭。

忘记密码：先停止服务，然后双击 `重置管理密码.bat`。首次设置与重置使用同一个本地窗口，输入两次新密码并按需点击小眼睛。仅更新密码哈希、认证状态和会话签名密钥，让旧登录令牌失效；保留用户名、端口、二步验证、QQ、API Key、插件和聊天数据。服务仍运行、配置损坏或写入失败时会提示，原配置不会被覆盖。二步验证已启用时仍需原二步验证码。

旧包遇到“直接进入登录页、没有自己设置过密码”：关闭旧服务，把 `QQ-AI-Bot-Windows-Launcher-Patch.zip` **解压到原安装目录并覆盖启动器文件**，不要另建一个空目录，也不要删除 `data`。补丁不含框架、运行时或任何 data 文件，不重装依赖。双击新增的 `重置管理密码.bat`，设置密码后重新启动即可。旧配置即使带有测试生成的随机密码，也会要求本机用户重新设置；不会再从环境变量取密码。

人格修改：编辑 `data/plugins/astrbot_plugin_qq_ai_lab/personas/*.json` 中的提示词，保存后重载插件；`/人格 名称` 可切换，无需改 Python。恢复默认请从用户包 `程序文件/personas` 复制原文件。人格只影响文字风格，不授予工具或系统权限。

费用显示是**按自定义保守单价计算的估算上界**，默认每百万 Token 100 元，并非 DeepSeek 官方报价或实际账单。调用返回真实 usage 时按它统计；失败、取消或缺失 usage 时保留请求前的保守预算。实际扣费以你的 DeepSeek 控制台为准。若调整单价，请先核实自己的供应商价格和币种。

本地 `data` 中有 Key、QQ Secret、配置和经手动保存的记忆，属于私密目录。不要上传、截图或直接分享整个安装目录。移动已配置的目录等于移动这些私密数据。此包不提供自动调试包导出。
