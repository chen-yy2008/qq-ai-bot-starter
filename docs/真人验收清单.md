# 一次集中真人验收

仅由用户在本机填写 Key、QQ 官方机器人凭据并授权自己的群。不要将凭据、群消息原文或用户路径填进公共报告。

本次候选修复只需集中完成 A–E：

| 项目 | 操作和通过标准 |
|---|---|
| A 原生指令 | 自研插件开启，群内 `/help`、`/sid` 正常；私聊 `/help` 仍正常 |
| B 初始化 | 群内 `/身份` 返回真实群 ID 和发送者 ID；无需 DeepSeek、无模型请求 |
| C 真实模型 | 管理员和允许群、提供者绑定后 `/启用群聊 已告知群友`，再 `/吐槽 为什么大学早八这么折磨人`；必须是真实 DeepSeek 回复 |
| D 主动接话 | 群成员知情后开启短期上下文和主动模式，至少两位成员自然讨论，观察合适时机和频率限制；不要求每条必回 |
| E 重启 | 用顶层入口停止、重新启动；群授权、模型、人格和插件配置保留 |

失败时开启一次安全诊断、重启、复现、查看、关闭。记录阶段代码和错误类别即可，不发送 Key、身份或聊天原文。A–E 未通过之前，不发布正式 v1.0.0。下面是原始完整范围清单，可作为既有功能抽查参考。

- [ ] 从 GitHub 下载用户 ZIP；核对 SHA256；在没有 Python/Git 的 Windows x64 环境完整解压并启动。
- [ ] 在本地设置面板密码；登录原生 WebUI；配置自己的 DeepSeek 模型和 QQ 官方机器人。
- [ ] 获取身份 ID；设置管理员和允许群；发送 `/启用群聊 已告知群友`；`/自检` 返回真实模型响应。
- [ ] QQ 普通消息可被收到；经过明确告知，开启上下文后能接上最近的话题。
- [ ] 在 QQ 中允许主动发言；开启自然/活跃档，观察至少 10 分钟；没有刷屏或自我回复回路。
- [ ] `/闭嘴` 即时生效，明确命令仍能用；`/开麦` 恢复原档。
- [ ] 同一主题切换四套人格，回复风格可辨识。
- [ ] 发送一张获授权的静态图片；真实 DeepSeek 视觉调用成功；关闭图片后不再传图。
- [ ] 长期记忆默认关闭；明确告知后手动增加、查找、删除；另一群无法读取；退出记忆和清空功能生效。
- [ ] 串子、EMO、吐槽、真实歌/书推荐和纯文本格式适合手机阅读。
- [ ] `/状态` 的 usage 与供应商控制台相符（控制台计费可能延迟）；临时调小调用上限后能阻止新请求；未泄露凭据。
- [ ] 停止并重启后设置、手动记忆和预算保留；短期聊天内容不保留。

全部满足后，在本地记录环境、结果和限制，用不含身份或群消息的摘要更新验收报告；重新构建干净包、校验并上传。正式发布唯一 `v1.0.0`；任何受 QQ/Key 权限阻塞的项目都不能标记为通过。不要将已配置的安装目录作为发布源。
