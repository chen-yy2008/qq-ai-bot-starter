# QQ 毒舌群友

AI 奇妙实验室第二期：基于 AstrBot 4.29.0、QQ 官方 WebSocket 和 DeepSeek 的趣味开源 QQ 群友机器人。默认安静，群聊白名单和知情同意后才启用自研群聊；不承诺长期维护。

**v1.0.0 正式交付，用户已确认发布。** 用户已在真实 Windows + QQ 群确认连接入群、`/身份`、管理员与允许群配置、群内授权、DeepSeek 绑定和 @ 文字回复。主动插话、图片理解、长期记忆等未完成真人验收，按实验功能提供。具体证据与限制见 [验收报告](docs/验收报告.md)。

## 下载与启动

打开 [Releases](https://github.com/chen-yy2008/qq-ai-bot-starter/releases)，选择正式版资产 **QQ-AI-Bot-v1.0.0-Windows-x64.zip**，按 `SHA256SUMS.txt` 核对校验值。不要用 GitHub 的 Source code ZIP 代替用户包。

Windows 10/11 x64，建议可用空间至少 3 GB。完整解压后第一层就能看到 **启动机器人.bat**。无需预装 Python、Git、Docker 或 pip；自带官方 Python，**首次必须联网**安装 149 个带哈希锁定的依赖，不能离线首次安装。内部框架和依赖集中在“程序文件”。

首次启动先弹出本地密码窗口：两次输入，两个小眼睛分别显示/隐藏，默认隐藏。要求 12–128 位，含大小写字母和数字。随后自动打开管理面板，默认地址 `http://127.0.0.1:6185`、用户名 `astrbot`，使用刚设置的密码。请保存好密码。忘记时先停止，再双击 **重置管理密码.bat**；只修改认证字段，不清空 data。

## 配置顺序

1. 在面板添加 QQ 官方 WebSocket 适配器，AppID/AppSecret 只填本机；把机器人加到有权限的测试群，允许获取全部群消息及主动发言。
2. 开启插件，群内检查 `/help`、`/sid`，发送 `/身份` 获取真实群 ID 和自己的发送者 ID。无需先配置模型，不产生付费请求。官方 OpenID 不一定是日常 QQ 号或群号。
3. 在 AstrBot 访问控制中，把自己的发送者 ID 加入管理员；QQ 群主不会自动成为 AstrBot 管理员。把群 ID 加到插件 `allowed_groups`。保存并重载。
4. 在模型页面创建并启用官方 DeepSeek OpenAI 兼容模型，Base URL `https://api.deepseek.com/v1`、Key 只填模型页面。到插件 `provider_id` 选择**模型实例**：本次真人示例的源 ID 是 `deepseek`，模型名 `deepseek-flash`，应选实例 **`deepseek/deepseek-flash`**，而不是 `deepseek`。模型名称以账号实际可用列表为准。
5. 向群友说明隐私与使用方式后，由 AstrBot 管理员发送 `/启用群聊 已告知群友`。`/帮助`、`/状态` 不调用模型；`/吐槽 为什么大学早八这么折磨人` 或 @ 机器人会使用自己的 DeepSeek 额度，明确请求默认冷却 20 秒。
6. `/人格` 查看四种风格，管理员用 `/人格 理性吐槽役` 等切换。人格只影响表达，不保证模型回答质量。
7. 需要短期上下文时先告知成员并获得同意，再发送 `/上下文 开启 已告知群友`；需要实验主动模式再单独发送 `/主动 自然` 或 `/主动 活跃`。不要给 `/主动` 追加“已告知群友”。未 @ 时保持沉默可能是正常保护，详见 [新手指南](docs/新手安装指南.md)。

## 日常入口与数据

顶层提供启动、打开管理面板、停止、重置密码、**安全诊断.bat**、自检及首次使用。没有自动开机任务、强制更新或后台更新服务。

按项目所有者最终要求，仅交付新版 Windows 用户包、完整源码和 SHA256；不提供旧版一键升级或候选渠道衔接。现有已配置安装可继续使用，不要删除或覆盖其中的私密 data。排障见 [安全诊断说明](docs/更新与诊断.md)。

默认关闭上下文、长期记忆和主动发言；短期上下文最多 24 条、每条 400 字、10 分钟，仅内存中保留。长期记忆是管理员手动 `/记住`，不是自动保存全部聊天。成员可 `/退出记忆`、`/别吐槽我`，管理员可 `/闭嘴`。不绕过 QQ 权限，不保证任意群可用。

本机 `data` 含私密配置和记忆，切勿上传分享。排障用顶层安全诊断，查看脱敏阶段与错误类别，完成后关闭；不要分享原始聊天或密钥。
